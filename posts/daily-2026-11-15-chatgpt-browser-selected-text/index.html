网页只想读一段？用 ChatGPT 浏览器侧栏解释选中文字

小宇2026-11-15— 次阅读
AI与ChatGPT

遇到一篇很长的活动公告，你可能只想弄懂「报名和取消」这一段。已经在浏览器里打开网页时，可以用 ChatGPT 浏览器扩展把选中的文字带到侧边聊天，再问这一段有什么要求、哪些细节还得回页面找。

浏览器扩展是给浏览器加功能的小工具。侧边聊天是放在网页旁边的聊天面板，可以一边看原文一边对照回答。以下以桌面端配合 Chrome 为例，资料核对日期为 2026 年 11 月 15 日。OpenAI Docs 浏览器扩展指南

在实际看网页的浏览器里打开侧栏

首次设置时，打开 ChatGPT 桌面端的「设置 → 电脑使用」（Computer Use），找到 Chrome，按提示安装所需插件和浏览器扩展，再回到设置，确认浏览器旁显示「管理」（Manage）。浏览器入口是否可见取决于功能开放进度和工作区设置。如果你有个人和工作两套浏览器资料，先确认扩展装在当前使用的那一套里。OpenAI Docs 扩展安装步骤

用这个浏览器打开目标网页，点工具栏里的 ChatGPT 图标。图标收起来时，到扩展菜单里找。官方文档同时列出了 Edge、Brave 和 Vivaldi 的侧边聊天支持。Opera 用户可以从桌面端引用打开的标签页。OpenAI Docs 支持的浏览器与侧栏入口

选中一段时，把小标题和例外一起带上

用鼠标选中要问的文字，按侧栏提供的方式将选区带入聊天。如果正文写着「提前一天取消」，但下一句紧接着是「已领取材料的名额须联系工作人员」，两句可以一起选。带上小标题也有帮助，尤其是在同一页同时介绍线上和线下活动时。OpenAI Docs 关于引用标签页和选区的说明

下面是一段虚构的练习文本。假设页面小标题是「线下体验课」，正文写着「报名成功后，请提前十五分钟签到。临时不能到场，请在前一天取消。已领取材料的学员，请先联系工作人员。」可以连同选区发出这样的请求。

请用两三句话解释我选中的「线下体验课」规则。按到场和取消分别列出该做的事，并指出已领取材料时多了哪一步。若这段没有写取消入口或具体截止时刻，把这两项列为待确认。

核对回答里新增的细节

示例中，「前一天取消」说明了日期关系。假如回答写成「前一天晚上十二点前在 App 中取消」，就回到原文找这两个细节。还没看到的话，可以补一句「把具体时刻和入口标为待确认，并指出我该继续找哪一类说明」。下次看到「报名须知见下文」或「以场馆通知为准」，也可以把被引用的段落追加进来再问。OpenAI Docs 关于限定资料和标记缺失信息的提示指南

想了解整页时，可以从侧栏引用对应的标签页，并明确请它读哪些章节。只关心一条条款时，带上那一段和必要的上下文就够了。若侧栏入口暂时不可用，把你可以分享的段落连同标题贴到普通聊天里，也能使用上面的提问方式。

页面在普通浏览器开着，先确认用的是哪个浏览器

ChatGPT 桌面端的内置浏览器有独立的浏览记录和登录状态。想让 ChatGPT 使用你在日常 Chrome 中已经打开的活动页面，可以回到那个标签页打开扩展的侧栏，核对标题和选区后再发送。要在内置浏览器里查看同一个需要登录的页面，则要在内置浏览器中完成登录。OpenAI Docs 内置浏览器说明

读完后把回答和原段落并排看一遍。对于这个例子，只要确认签到时间、取消要求和领取材料后的处理方式三处都对得上，就能据此整理自己的待办。
