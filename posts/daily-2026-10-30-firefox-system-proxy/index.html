Firefox不跟Clash走？先查浏览器代理设置

小宇2026-10-30— 次阅读
客户端教程

同一台电脑上，另一个浏览器能打开网页，Firefox 却提示连接失败。如果正在用 Clash 科学上网，可以先检查 Firefox 自己的代理设置，看看它是否仍在使用以前填过的地址。

本文以 Windows 上的 Firefox 桌面版和 Clash Verge Rev 系统代理为例。资料核对日期为 2026 年 10 月 30 日。步骤依据官方说明整理，未对读者设备进行实际测试。

为什么同一台电脑，会有不同结果？

“代理”可以先理解为把联网请求交给指定工具转接。“系统代理”则是操作系统提供的一套连接设置，应用可以读取它，也可能采用自己的安排。Clash Verge Rev 官方文档说明，并非所有程序都会遵循系统代理设置。官方原理说明

Firefox 本身提供多种连接选项。若以前手动填过代理，或安装过管理连接的扩展，就值得先查看这一层。Mozilla 也建议，使用代理时，可将 Firefox 的设置与能够正常工作的浏览器作比较。Mozilla 官方排查说明

第一步：先确认是在比较同一个问题

保持同一网络、同一节点，在两个浏览器里打开同一个完整网址，记下 Firefox 的错误文字。

如果所有浏览器都打不开，先检查原网络和客户端连接；如果只有一个网站失败，也不能仅凭这一次结果认定是 Firefox 的代理设置出了问题。把范围记清楚，再往下查。

同时记录是否开启了 TUN，也就是通过虚拟网卡接管请求的方式，或其他 VPN。它们与系统代理是不同层面的设置，本文主要检查 Firefox 如何使用系统代理。

第二步：找到 Firefox 的连接设置

从 Firefox 菜单打开“设置”，寻找“代理设置”，再进入“配置代理”或“设置”按钮。

Mozilla 当前说明列出了不同界面的入口：一种在“常规”页面的网络设置或代理设置中；另一种在“隐私与安全”页面，经过连接与软件安全、高级设置，再进入代理设置。按自己界面寻找，不必因为按钮移了位置就重装浏览器。官方设置入口

修改前，记下原先选中的项目和已有内容。如果这些是单位要求的连接设置，先按设备管理要求核对。

这几个选项，分别是什么意思？

Firefox 中的选项 可以怎样理解
不使用代理 Firefox 不主动使用这里配置的代理
使用系统代理设置 读取 Windows 已配置的代理设置
手动配置代理 使用你在 Firefox 中填入的地址和端口
自动代理配置网址 按指定脚本判断怎样连接，常见名称是 PAC

“端口”可以先理解为程序接收请求的入口编号。这些选项的用途见 Mozilla 官方连接设置说明。

如果你的目标是让 Firefox 跟随 Clash 设置到 Windows 的系统代理，可以选择“使用系统代理设置”，按窗口提示确认，再重新访问刚才的网址。若本来就需要独立的手动配置，则应核对对应地址，保留自己的使用目的。

“不使用代理”也不能说明整台电脑完全直连；若另有 TUN 或 VPN 接管，实际路径还需要分别检查。

第三步：核对 Windows 和客户端是否一致

在 Windows 设置中进入“网络和 Internet → 代理”，查看当前配置。微软官方说明，这里可以管理自动检测、配置脚本和手动代理。微软代理设置说明

对照 Clash 当前显示的地址和端口，确认自己没有在 Firefox 中沿用其他软件留下的旧值。具体数值以正在使用的客户端为准，不要照抄别人的端口。

如果 Firefox 已经选择读取系统设置，而 Windows 中相关代理没有按预期启用，就回到客户端检查系统代理开关，再做同一个网页的比较。

第四步：留意是否有扩展控制连接

Mozilla 说明，连接设置窗口会显示控制联网方式的扩展，并提供停用入口。若看到相关提示，先记下扩展名称；在自己管理的设备上，可以暂时停用对应扩展作比较，再按需要恢复。官方扩展控制说明

每次只改一个项目。测试后恢复无效改动，保留确实有帮助的结果，避免浏览器、系统和扩展同时各用一套不同设置。

Firefox 采用系统代理后，进入 Clash 的请求还会受其路由模式和规则影响。因此，设置选对了，仍要检查实际需要的网站能否正常使用。官方规则说明

仍未解决时，整理 Firefox 版本、错误文字、所选代理方式和对照结果，再继续求助。提供这些信息，比反复更换机场节点更方便缩小检查范围。
